# Global Tech schedule has changed

The Sunday-only task specification has been superseded by the [daily task specification](daily-codex-task.md): **every day at 02:00 Asia/Hong_Kong**, using the strongest model and highest reasoning setting supported by the native scheduler.

Saving these instructions does not create or activate a platform task. Registration and model selection remain pending until confirmed in the native Scheduled/Automations interface. Update an existing Global Tech task instead of keeping both weekly and daily schedules.
